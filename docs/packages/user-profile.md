# user-profile

**Composer:** `ohlcx/user-profile` · **Repository:** [github.com/ohlcx/user-profile](https://github.com/ohlcx/user-profile) (private) · **Edition:** Pro, Light

## Role

Jetstream profile management components with a headless layout, and an API for the same actions: profile information, photo, password, browser sessions, account deletion.

## Surfaces

- Web endpoints under `/components/*` that render the profile forms for embedding
- `/api/user-profile/*` routes for the React SPA

## Related

MCP tools: `update-profile`, `update-password`, `delete-profile-photo`, `get-sessions`. See [Profile and settings](../mcp/tools/reference.md#profile-and-settings).
